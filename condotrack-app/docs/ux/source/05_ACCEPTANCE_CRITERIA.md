# CondoTrack — Acceptance criteria / QA v01

## Global
- [ ] No existen diagonales decorativas globales.
- [ ] Rothek se carga desde el proyecto y se verifica en DevTools/computed styles.
- [ ] Títulos de pantalla no dominan la interfaz.
- [ ] Fondo usa tonal field/gradiente sutil donde corresponda, no gradientes genéricos.
- [ ] Glass se usa en controles/capas, no indiscriminadamente.
- [ ] Estados no dependen solo del color.
- [ ] Mobile no presenta overflow horizontal.
- [ ] Navegación inferior no tapa contenido.

## R01
- [ ] Header compacto.
- [ ] Contexto edificio/unidad visible sin ocupar un hero completo.
- [ ] Primary Context Widget cambia entre vistas relacionadas.
- [ ] Quick actions se distinguen claramente.
- [ ] Live cards apiladas solo entre objetos equivalentes.
- [ ] Visitas hoy usa asset correcto.
- [ ] Todo en orden no tiene overlays/radios rotos.

## R20
- [ ] Resumen legible antes de detalle.
- [ ] Gráfico aparece bajo demanda.
- [ ] Medios de pago/documentos no inflan la vista principal.
- [ ] No se cuelga al abrir composición.

## R05
- [ ] Calendario ocupa jerarquía principal.
- [ ] Fecha seleccionada es obvia.
- [ ] Seleccionar fecha actualiza horarios.
- [ ] Se puede completar la reserva.
- [ ] No se muestra información de disponibilidad innecesaria antes de selección.

## R06
- [ ] Crear nueva visita es un botón convencional.
- [ ] Selector de día funciona.
- [ ] Flujo tiene pocos pasos.
- [ ] “Autorizar y emitir pase” queda como acción final.

## Bottom navigation
- [ ] 5 destinos máximos.
- [ ] Acción central Acceso/QR destaca sin convertir toda la barra en amarillo.
- [ ] Labels/iconos son comprensibles.
- [ ] Touch targets adecuados.

## Motion
- [ ] Animación refuerza jerarquía o relación.
- [ ] No existe motion decorativo que ralentice tareas.
- [ ] Reduced motion tiene fallback.
