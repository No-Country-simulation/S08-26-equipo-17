Este pack reúne el **fondo aprobado**, el **target visual del Home**, los **mockups de pantallas internas** y un **prompt de ejecución unificado** para que Codex / Cloud Code continúe el trabajo sin reinterpretar el sistema.

## Cómo usarlo

1. Abrir primero el target Home y el background abstracto aprobado.
2. Leer el análisis y el Visual System Lock.
3. Ejecutar el prompt `02_CODEX_EXECUTION_PROMPT_R15.md` sin reescribirlo.
4. Pedir que trabaje en dos bloques:
   - A. Refinamiento definitivo del Home + sistema global.
   - B. Adaptación del mismo sistema a las pantallas internas.

## Criterio general

No volver a explorar estilos.  
No inventar nuevas composiciones.  
No mezclar referencias de manera libre.  
Todo debe derivar del target R1.4 y del fondo abstracto aprobado.
