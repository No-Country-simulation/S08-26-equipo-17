Do not treat the current UI as a visual baseline. Preserve logic, state, data and routing, but rebuild the presentation from the targets in this pack.

Before coding:
1. Open `01_VISUAL_TARGET_MANIFEST.md`.
2. Inspect every local image referenced for the current phase.
3. Open the source URLs when interaction/motion behavior matters.
4. Read `02_CODEX_EXECUTION_PROMPT.md`.
5. Only then modify code.

## Rule for references
- **LOCAL IMAGE = visual target** (composition, hierarchy, density, materiality, component anatomy).
- **SOURCE URL = interaction/context target** (motion, behavior, responsive behavior, additional screens).
- **CondoTrack tokens/branding = final adaptation layer.**

Do not finish a module by merely restyling the existing card. If a target shows a different component anatomy, rebuild the anatomy.
